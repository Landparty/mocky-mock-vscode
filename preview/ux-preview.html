Program and suite, one click apart

      
On a program that already has a suite, the beaker opens that suite instead of offering to create one. A suite's title bar has a button back to its program. Ctrl+Alt+O (Cmd+Alt+O on macOS) flips between them.

      before: the beaker always said New Test Suite
    

    

      
Right-click entry points

      
New Test Suite, Fill In Missing Mocks and Export Mainframe-Ready COBOL are in the editor and Explorer context menus and the title bar's "…" menu, so you rarely need the Command Palette.

      before: palette only for Fill and Export
    

    

      
A status bar that stays quiet

      
When everything works, it shows just the name and a check. A problem turns it yellow or red and says what to do. Hover for the reason, plus links to Check Setup, the guide and settings.

      before: ✓ mockymock: ready, same colour for every state
    

    

      
Plain-language commands

      
Every command has an icon. "Fill In Missing Mocks" drops the CLI flag from its name and shows progress while it runs.

      before: Fill Missing Mocks (mockymock generate --fill)
